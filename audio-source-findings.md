# Optional Free Stock Sound Fallback Findings

This note records sources to consider only if the strengthened built-in Web Audio cues still feel insufficient during rehearsal testing.

| Source | Practical use | License and attribution notes | Caveats |
| --- | --- | --- | --- |
| Pixabay Sound Effects | Good first option for storm, lightning, crash, rumble, magic shimmer, and fanfare searches. | Pixabay states that content may be used for free, without attribution, and may be modified, subject to prohibited uses. | Do not redistribute the raw file as a standalone asset outside the soundboard; check each item for recognisable third-party content or special issues. |
| Mixkit Sound Effects | Good option for impact, thunder, transition, whoosh, fanfare, and theatre-like cue sweeteners. | Mixkit states that sound effects are royalty-free, usable in commercial and personal projects, and attribution is appreciated but not required. | Review individual downloads and avoid overusing generic trailer-style hits if the show needs a comic Greek pottery style. |
| Freesound | Deep catalog for niche sounds and theatrical textures. | Freesound files are user-uploaded under Creative Commons licenses; CC0 is easiest, CC-BY requires attribution, and CC-BY-NC should be avoided if there is any commercial/public performance ambiguity. | Requires careful per-file license checking and an attribution list if any CC-BY sounds are used. |

Recommendation: keep the newly strengthened generated cues as the primary version for now because they avoid external file management, licensing, attribution, download dependencies, and deployment media size issues. If rehearsal playback still feels weak on the actual speaker/projector setup, the safest external enhancement path is to select a small number of Pixabay or Mixkit files, upload them through the web static asset workflow, and document sources in an attribution note.
